## How to wire a new SDK organism into the organism

**Step 1 — Define the resident type** in `types/house_architecture.mo` or the organism's specific type file. All fields must be non-mutable at the type level (mutable state lives in the actor via `var` or collection types).

**Step 2 — Create the computate function** in the corresponding `lib/` module. Signature: `computate(resident: OrganismResident, houseStates: [HouseState], beat: Nat) : ComputateOutput`. The computate always returns a typed output record — never Void, never Text. The output feeds into the ADRE world-model.

**Step 3 — Wire into main.mo** via the corresponding mixin. The mixin receives the organism's resident state slice via parameter injection. The mixin's `heartbeat()` function calls `computate()` and updates the world-model.

**Step 4 — Wire into ADRE** — The computate output must be added to the ADRE sense() pass. ADRE reads all organism outputs at the start of every 873ms cycle.

**Step 5 — Add query** — Expose `getSDKOrganismState(organism: SDKOrganism) : async SDKOrganismOutput` from main.mo so the frontend can display real organism state.
